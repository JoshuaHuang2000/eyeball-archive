# 佩特洛娃线捕捞：按单细胞飞行史重算能源收支

**2026-09-11｜[工程架构](./petrova-line-harvester)补充计算｜基于[原书参数核对](./petrova-line-source-audit)**

在满能出发、加速至 0.92c、再靠自身光子推进减速入罐的假设下，单细胞入罐质量约为 **696 pg**，仍是原先直接使用的 20 pg 的 **34.8 倍**。单细胞剩余储能约为 **60.8 kJ**，按入罐总质量计的比能约为 **87.3 PJ/kg**。

因此可以重算整套能源产出与推进收支。相同细胞计数率下，质量产率提高 34.8 倍；相对于旧的“20 pg × 45 PJ/kg”口径，毛储能产率提高 **67.5 倍**。这是修正细胞质量和能量状态后的条件性结果，不是对尚未测量的捕获率作保证。本文不估计市场价格、项目利润或货币回收期。

## 1. 统一单细胞状态

原书 PDF 第 109–110 页报告单细胞吸收 1.5 MJ、增重约 17 ng；第 60 页报告早期样本约 20 pg。本文额外假设后者可以近似为不用于推进的载体干质量。原书未明确证明该干质量，故它是模型参数。

取 mᵦ = 20 pg，E₀ = 1.5 MJ，c = 299,792,458 m/s：

```text
满能总质量 m₀ = mᵦ + E₀/c² ≈ 16.710 ng
```

理想光子火箭的质量比由累计快度变化决定：

```text
mᵢ/m𝒇 = exp(Δχ)
χ = atanh(v/c)
```

从静止加速到 βc，再制动至同一参考系中的静止，累计快度变化为 2 atanh(β)：

```text
q = m𝒇/m₀ = (1 − β)/(1 + β)
E𝒇 = (m𝒇 − mᵦ)c²
ε𝒇 = E𝒇/m𝒇 = c²[1 − mᵦ/(q m₀)]
```

在 β = 0.92 时，q = 1/24，因此：

| 量 | 数值 |
| --- | ---: |
| 入罐总质量 | 0.69624 ng = 696.24 pg |
| 其中载体质量 | 20 pg |
| 剩余可用储能 | 60.78 kJ/cell |
| 剩余储能占出发值 | 4.05% |
| 入罐产品比能 | 87.29 PJ/kg |
| 1 g/day 产品对应储能流率 | 1.010 GW |

飞行消耗了约 96% 的储能，但这部分能量对应的静质量也被消耗。因此剩余产品仍有约 97.1% 的质量对应储能，比能并没有按剩余能量比例下降。

这套结果要求理想定向光子排放、载体不被消耗、无额外漏热和明显转向代价。起终点相对太阳的轨道速度、引力与偏航未纳入这一数量级模型。入罐能量已经扣过完整制动，不应再扣一次同样的减速成本。

### 1.1 速度与干质量仍可改变结果

| 峰值速度 | 入罐总质量 | 单细胞剩余能量 | 产品比能 |
| ---: | ---: | ---: | ---: |
| 0.50c | 5.570 ng | 499 kJ | 89.55 PJ/kg |
| 0.80c | 1.857 ng | 165 kJ | 88.91 PJ/kg |
| 0.90c | 0.8795 ng | 77.24 kJ | 87.83 PJ/kg |
| 0.92c | 0.6962 ng | 60.78 kJ | 87.29 PJ/kg |

同一峰值速度下，理想模型的结果不直接取决于航行距离；真实任务中距离会影响可达到的速度、响应时间和附加损耗。若来流是混合状态，应累加每组细胞的数量乘剩余能量，不应把平均速度直接代入非线性公式。

### 1.2 与完整繁殖往返的相容性

如果去程和回程都达到 0.92c、都自行制动，并在行星上复制成两个 20 pg 载体、平分储能，即使复制本身不耗能，也不够完成全周期。初始满能/干质量比约为 835.5；双程及复制的最低要求为 2 × 24² = 1,152。

两段采用相同峰值速度时，上限约为 0.9067c；如果去程为 0.92c，回程上限约为 0.8913c，且均未留额外能量余量。因此本文 0.92c 是第一次加速—减速的捕获压力情景，不声称整个自然生命周期的两段必然都如此。原文“可达 0.92c”不要求每段都达到这个峰值。

## 2. 同一计数通量下，产出怎样变化

为与此前讨论直接比较，继续取未实测的参考计数率：

```text
Ṅref = 6.3 × 10⁸ cells/s
```

它继承 ArcLight 采样面积和周期假设、富集方向占比、向 0.30 AU 的通量搬移，以及约 18 万 km² 光学面积模型。这些不确定性没有因质量修正而消失。

以 η꜀ 表示光束重叠、行为响应、末端入罐及留存的综合计数效率。假设所有留存细胞符合上节状态：

```text
Ṅ = Ṅref η꜀
ṁ = Ṅ × 696.24 pg
Pstored = Ṅ × 60.78 kJ
```

| 综合计数效率 η꜀ | 毛入罐产品 | 毛储能流率 |
| ---: | ---: | ---: |
| 100%（理想算术基准） | 37.90 kg/day | 38.29 TW |
| 1% | 378.98 g/day | 382.90 GW |
| 0.1% | 37.90 g/day | 38.29 GW |
| 0.01% | 3.790 g/day | 3.829 GW |

旧的 20 pg 和 45 PJ/kg 相乘，相当于每细胞只有 900 J。现在同一计数单位对应 60,777 J，因此储能产出倍数为 67.53。不能把质量乘 34.8 后，又把能量再乘 67.5；后者已经包含前者。

在这一计数基准下达到 10 g/day，只需 η꜀ ≈ 0.0264%。这是目标效率的反推，不是实际效率的下界。若真实计数通量仅为基准的十分之一，达到同一产量的所需效率就提高十倍。

## 3. 驻留与运输的单位产品成本

仍用工程稿的 100 kg 总质量、圆轨道共面参考位置、金星角速度和理想光子推进。换用入罐产品比能 87.29 PJ/kg：

```text
驻留产品消耗 ṁkeep = M a c / ε𝒇
```

| 站位 | 驻留推力 | 驻留光子功率 | 每日产品消耗 |
| --- | ---: | ---: | ---: |
| 0.30 AU | 6.118 N | 1.834 GW | 1.815 g |
| 0.50 AU | 1.587 N | 0.476 GW | 0.471 g |

质量修正不会改变给定站体质量所需推力，也不会改变 Fc。它只是提高每公斤产品可提供的冲量；尾焰隔离和热设计仍须处理这些光子功率。

沿用示例运输预算：100 kg 近似恒定运输质量、往返总 Δv = 45 km/s，以低速冲量估算：

```text
mtransport ≈ Mtransport Δv c / ε𝒇 ≈ 15.45 g/往返
180 个生产日摊销 ≈ 0.0859 g/day
```

45 km/s 仍是预算输入，不是已验证的近地轨道往返轨迹。180 日也是示例服务周期；高产量时需要更频繁运输或更重载荷，不能固定沿用 100 kg 运输器。首次部署成本也需另外摊销。

## 4. 条件性净收益与收支平衡效率

先仅扣驻留与上述运输摊销，不计其他系统损耗：

```text
ṁpartial-net = ṁcapture − ṁkeep − ṁtransport
```

0.30 AU 的两项合计约为 1.901 g/day。

| η꜀ | 0.30 AU 毛产量 | 扣两项后的余量 | 余量的储能流率 |
| ---: | ---: | ---: | ---: |
| 1% | 378.98 g/day | 377.08 g/day | 380.98 GW |
| 0.1% | 37.90 g/day | 36.00 g/day | 36.37 GW |
| 0.01% | 3.790 g/day | 1.888 g/day | 1.908 GW |

因此参考条件下，仅支付这两项所需的计数效率为：

```text
η꜀,break-even ≈ 1.901 / 37,897.7
              ≈ 0.0000502 = 0.00502%
```

约为理想参考细胞数的 **两万分之一**。完整门槛应加上运行、漏热、储存损失与启动摊销；如果推进动量效率低于 1，驻留和运输项需相应提高。

用额外等效功率 Pother 记账，可写为：

```text
η꜀,break-even = (Pkeep + Ptransport,avg + Pother) / (Ṅref E𝒇)
```

这里约 38.29 TW 是分母的条件基准。局部硬件即使承受不了较小的漏热功率，也可能先于能量收支失效，所以净能源充足不能代替硬件验证。

### 4.1 比较 0.50 AU 时同步修正光学面积

若当地计数通量及入罐状态保持相同，但采用原稿的金星竞争信号几何，0.50 AU 的光学面积约为 0.30 AU 的 0.278 倍。对应：

| η꜀ | 0.50 AU 毛产量 | 扣驻留与示例运输后 | 余量的储能流率 |
| ---: | ---: | ---: | ---: |
| 1% | 105.33 g/day | 104.77 g/day | 105.85 GW |
| 0.1% | 10.53 g/day | 9.976 g/day | 10.08 GW |
| 0.01% | 1.053 g/day | 0.496 g/day | 0.502 GW |

两项消耗合计约 0.557 g/day，平衡效率约 0.00529%。这与 0.30 AU 接近：更低的驻留成本，被更小的参考光学面积部分抵消。实际最优站位还取决于非共面轨迹、通量、速度与热设计。

## 5. 重新扩大产量后，必须重新考虑库存

所有 100 kg 驻留数字都是给定总质量工作点的计算。若产品连续堆在站内，必须让 M(t) 包含库存、容器和残余细胞。驻留消耗随 M(t) 增长。

例如 η꜀ = 1% 时，0.30 AU 的毛产品 180 天约为 68.2 kg；100% 算术基准则约为 6.82 t。这都不能忽略于 100 kg 站。即使 η꜀ = 0.1%，180 天也积累约 6.82 kg 毛产品。

更完整的库存方程是：

```text
dmstock/dt = ṁcapture − k[Mhardware + mstock(t)] − ṁother − ṁexport
k = a c / ε𝒇
```

各速率使用同一时间单位；式中暂假设耗尽残余已排出，或另计入硬件/库存质量。小批量高频运输可抑制驻留质量增长，但增加交接与运输次数。只有把运输周期、载荷和罐体一并设计，才能将表中短期余量转为长期年产量。

## 6. 对工程经济性的含义

可以重算、且已重算的，是同一计数通量下的产品质量、储能产出、驻留产品消耗、运输产品消耗和条件性自持门槛。结果显著改善：0.1% 计数效率的参考情景，在 0.30 AU 扣两项消耗后仍约有 36 g/day，约 36 GW 储能流率。

尚不能从这些数字直接得出的，是实际产量、建造和运维成本、地面可售电量、货币回收期与可实现部署速度。需要把实际计数率、入罐能量、可用率、库存轨迹、完整消耗和接收系统测出来，才能补齐这些项。

**本次修正的意义是：在统一单细胞飞行史后，能源收支的可行区间明显扩大；其依据不再是把早期 20 pg 样本错误地当成富集产品。**

计算脚本位于仓库 `scripts/plh_economics.py`，使用 Python 标准库，可运行 `python3 scripts/plh_economics.py` 复算。它保留 6.3 × 10⁸ cells/s 的舍入比较基准，避免将新增有效位数误作更精确的流场预测。
